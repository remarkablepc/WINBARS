📂 1. Restoring User Files & Folders (Zero Software Required)

Your files are stored in 100% standard Windows NTFS format with original file names, dates, and folder trees preserved.

  • Connect this drive to any working computer (Windows, macOS, or Linux).
  • Open the Users\ folder located on the root of this backup drive.
  • Drag and drop your Desktop, Documents, Downloads, Pictures, and other data directly back onto your computer.
Accidentally deleted or modified a file?
WINBARS preserves deleted and replaced files for 30 days in the \_DeletedArchive\YYYY-MM-DD\ folder on this drive.

🔌 2. All-in-One Bootable Backup Drive or Dedicated Rescue USB

If the target computer won't boot, you can turn any blank USB drive into a dedicated rescue tool, or make this backup drive itself bootable:

  • Option A - Make This Backup Drive Bootable (Non-Destructive):
    Plug this drive into any working Windows PC (or your own). Right-click Create-RescueUSB.bat on the root of this drive and select Run as administrator. Select this drive: WINBARS will non-destructively carve out a 2 GB FAT32 UEFI boot partition (WINBARS_BOOT). All existing user backups, system images, and files remain 100% untouched!
  • Option B - Dedicated Technician Flash Drive:
    Plug in a blank USB flash drive (4 GB+) and run Create-RescueUSB.bat to format it as a dedicated portable UEFI WinRE recovery drive.

🛡️ 3. Emergency Blue Screen / Registry Rollback (Shift + F10)

If Windows is trapped in a reboot loop or blue screen (BSOD) after an update or driver install:

  • Boot the failing computer into the Windows Recovery Environment (WinRE) (hold Shift while clicking Restart, tap F11/F12 at boot, or boot from a Windows Setup / Rescue USB).
  • Select Troubleshoot → Advanced options → Command Prompt (or press Shift + F10 on any Windows Setup screen).
  • The Notepad Graphical File Manager Trick:
    If you aren't sure which drive letter was assigned to your backup drive in WinRE, simply type: 
    notepad
    Press Enter, then click File → Open and change "Files of type" to All Files (*.*). You now have a full graphical Windows Explorer window to visually see drive letters, browse files, and right-click to run scripts!
  • Run the emergency recovery assistant from your backup drive (typically drive D: or E:): 
    D:\EMERGENCY_RECOVERY.bat
    (Or E:\EMERGENCY_RECOVERY.bat if your CD/system reserved shifted the letters)
  • Select [1] Offline Registry Rollback. WINBARS will automatically locate your Windows installation on disk, back up the corrupt hives, and restore pristine uncorrupted hives.
  • Type exit and click Continue to Windows.

💾 4. System Image Restore (Safe Overlay vs. Clean Wipe)

System images captured by WINBARS are stored in \SystemRecovery\ (or legacy \SystemImages\) (e.g. SystemImage_OS_and_Programs_*.wim).

Two Recovery Pathways Available:
• Option [1] Safe Overlay (macOS-Style Non-Destructive Refresh): Overlays Windows OS and Program Files from the .wim image while leaving C:\Users\ 100% untouched on disk. Perfect when Windows is corrupted or bluescreening but client data remains on drive C:.
• Option [2] Bare-Metal Clean Wipe & Re-Format: Completely wipes and re-formats drive C: before applying the image. Use for drive replacements (new SSDs) or catastrophic malware. Enforces mandatory two-step confirmation.
  • Boot the target computer into WinPE/WinRE (via Windows Setup USB, our Rescue USB, or Bootable Backup Drive).
  • Press Shift + F10 to open the recovery Command Prompt.
  • Switch to this backup drive and launch the recovery assistant: 
    D:\EMERGENCY_RECOVERY.bat
    (Or run D:\Apply-SystemImage_WinPE.bat directly)
  • Choose Your Restore Method:
    1. Option [1] Safe Overlay: Refreshes OS & Program Files while preserving all existing user folders and files on disk.
    2. Option [2] Bare-Metal Wipe: Prompts for two-step confirmation, formats drive C:, and applies fresh OS image.
  • Once DISM completes (typically 5–15 minutes), the script automatically invokes BCDBoot to rebuild the UEFI bootloader.
  • Reboot the PC into your freshly restored Windows environment.

🔐 5. BitLocker Emergency Recovery Keys

If Windows displays a blue BitLocker prompt asking for a 48-digit numerical recovery key:

  • Open this backup drive on any working computer or mobile phone (via USB-OTG).
  • Locate BitLocker_Recovery_Key.txt (or inside Backup_Logs\BitLocker_Recovery_Key.txt).
  • Enter the 48-digit numerical password on the locked computer screen to unlock the drive.

👁️ 6. Cloaking / Hiding this Backup Drive in Windows Explorer

To protect this backup drive from accidental tampering or ransomware visibility while permanently connected:

  • Right-click Toggle_Backup_Drive_Visibility.bat on the root of this drive.
  • Select Run as administrator.
  • The script will toggle whether this drive is visible or cloaked in 'This PC'. Backups continue running silently in the background even when cloaked.
